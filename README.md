## Formación en Riwi

### 1. Ruta Básica — Fundamentos de Software

- **Python:** lógica, POO, manejo de archivos, errores y módulos.
- **HTML + CSS:** maquetación semántica, diseño responsive, Flexbox y Grid.
- **JavaScript:** DOM, eventos, Fetch API y lógica frontend.
- **Bases de Datos:** modelado, SQL, joins, restricciones e integridad.
- **Proyecto Integrador — CoDecide:** proyecto colaborativo que integra todos los conocimientos de la ruta básica (frontend + backend + base de datos).

### 2. Ruta Avanzada — Analítica de Datos

Lenguaje principal: **Python**.

- **Pandas:** limpieza, transformación, groupby y merges.
- **EDA:** estadística descriptiva, visualización, tratamiento de nulos y outliers.
- **ETL:** procesos de extracción, transformación y carga.
- **Power BI:** modelado, DAX básico y dashboards interactivos.
- **Arquitectura de Datos:** diseño por capas y buenas prácticas.
- **Apache Spark:** procesamiento distribuido con DataFrames.
- **Apache Airflow:** orquestación y DAGs.
- **Docker:** entornos de datos reproducibles con contenedores.

### 3. Ingeniería de Datos — En curso

- **FastAPI:** APIs para exponer datos y modelos.
- **Consola AWS e IAM:** usuarios, roles, políticas y seguridad.
- **VPC:** redes, subredes y grupos de seguridad.
- **EC2:** despliegue de aplicaciones y servicios.
- **ECR + ECS:** imágenes Docker y contenedores en la nube.
- **S3:** almacenamiento de archivos y datasets (data lake).
- **RDS:** bases de datos relacionales gestionadas (en práctica).
- **Objetivo final:** pipeline end-to-end: ingesta, procesamiento (Spark / Pandas), orquestación (Airflow), almacenamiento (S3 / RDS), API (FastAPI) y visualización (Power BI).

**Objetivo profesional:** Data Engineer capaz de construir pipelines completos desde la ingesta hasta la visualización.
